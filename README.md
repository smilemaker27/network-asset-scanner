# Network Asset Scanner

A beginner cybersecurity project built with Python and Nmap on Kali Linux.

## Features

- Scan a target host
- Detect open ports
- Identify services
- Generate timestamped reports
- Store reports automatically

## Technologies

- Python
- Nmap
- Kali Linux
- VMware

## Usage

python3 scanner.py

## Example Output

Port: 135 | Service: msrpc
Port: 139 | Service: netbios-ssn
Port: 445 | Service: microsoft-ds
